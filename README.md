# Codex Roblox Clone

This is a simple PHP MVC application demonstrating login and registration functionality. It uses SQLite for storage and a very basic style reminiscent of Roblox.

## Setup
1. Ensure PHP with SQLite support is installed (XAMPP typically includes this).
2. Place the repository contents under your XAMPP `htdocs` directory, e.g. `codex-roblox-clone`.
3. Access `http://localhost/codex-roblox-clone/` in your browser.

The application will create a `database.sqlite` file automatically on first run.
